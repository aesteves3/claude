# Course images (local)

These files are served at `/images/` on the site:

| File | Used for |
|------|----------|
| `arrais1.png` | Arrais Amador course card + detail |
| `mestre1.png` | Mestre Amador course card + detail |
| `cap1.png` | Capitão Amador course card + detail |

Referenced in `src/components/home/CoursesSection.jsx` and `src/pages/CourseDetail.jsx`.

After changing images, run `npm run build` so they are copied into `dist/images/`.
